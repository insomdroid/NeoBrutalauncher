03 / Why this exists

Minimalism had its moment.

NB Launcher started with a simple idea: phones are capable of so much, so why should every homescreen look the same?

This project is an experiment in creativity, curiosity, and building with AI. The ideas and direction are human; AI helped turn them into working software.

05 / Quick answers

Good to know.

Is NB Launcher free?

This is the free NB Launcher repository. Check the repository and release notes for the current build and its terms.

How do I download it?

Open GitHub Actions for build artifacts, or visit Releases for published versions. Availability depends on the latest workflow and release status.

Can I contribute or report a problem?

Yes. Visit the GitHub repository to explore the source code, open an issue, or share suggestions.

Is this an official Google app?

No. NB Launcher is an independent community project and is not affiliated with Google.
